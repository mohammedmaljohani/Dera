# Dera — one live picture for disaster response

**MEDATHON 2026 · Track 1: Healthcare Crowd & Patient Flow Management · Team AidFlow (MED-AULCUT)**

**▶ Live demo: https://mohammedmaljohani.github.io/Dera/**

Dera puts command, dispatch, ambulance crews and hospital emergency departments on one shared screen during a disaster. It sets how serious each incident is from its facts, suggests which unit to send and which hospital can still take each ambulance's patients, and shows the reason for every suggestion. A person approves every critical decision. Arabic and English, computer and phone.

## Try it

1. Open the **[live demo](https://mohammedmaljohani.github.io/Dera/)**. Nothing to install.
2. Press **Start demo**. Subtitles explain each event in a simulated Jeddah flash flood.
3. Switch role at the top right (Commander, Dispatcher, Hospital ED, Field Units) and language with the globe button (**ع** / **EN**).

## Good to know

- **All data is simulated** and all hospitals are fictional. No real system or patient data is connected.
- Levels and suggestions come from **fixed, explained rules, not AI**. They still need expert review. Dera is **not a clinical triage tool**.
- Built with React, Tailwind CSS and an offline map of Jeddah from OpenStreetMap data (© OpenStreetMap contributors, ODbL). The source code is in `src/`. Automated browser tests (264 checks) were run during development.
